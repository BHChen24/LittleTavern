## Evidence for the startup and messaging findings

These observations concern existing code and the proposed sequence, not an executed implementation:

- `packages/data/src/paths.ts:20-41`: `resolveAppPaths()` calculates paths; it does not create
  the directories. `ensureImportFolders()` creates them at lines 44-49.
- `packages/tui/src/app.ts:294-295`: `createApp()` currently invokes `ensureImportFolders()` and
  displays its notice. `startApp()` invokes `createApp()` at line 941.
- `research.md:81-82` and T003 require exclusive-create copies, while T005 schedules the helper
  before `startApp()`. No preceding folder-creation step is specified.
- `packages/data/src/settings.ts:54-57`: `writeSettings()` calls `mkdirSync` and `writeFileSync`
  without handling their failures. A durable marker cannot be guaranteed if those writes fail.
- `packages/tui/src/library-format.ts:3-4`: `EMPTY_LIBRARY_HINT` explicitly includes
  `/import <path>`. This remains reachable when examples are missing, fail, or have been deleted.
